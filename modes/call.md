# Mode: call — Call opener, voicemail, objection prep

Requires: graded lead with dossier; `preferences.yml` must allow calls for the
segment (never recommend a call otherwise). DRAFT-ONLY: scripts for the HUMAN
to deliver; nothing is dialed.

Produce, all grounded in Blocks B/C/E of the dossier (sourced hooks only):
1. **Opener (≤30s)**: hook → one-line who-you-are → permission ask
   ("bad time?"). Written for speech: short words, no subclauses.
2. **Voicemail (≤20s)**: hook + name + callback + email fallback. One take.
3. **Objection prep**: the 4 likeliest pushbacks for this persona/segment
   ("we have someone", "no budget", "send an email", "not a priority") each
   with a 2-sentence response drawn from proof points — concede honestly where
   the user lacks evidence.
4. **Goal**: define the single success outcome (usually: agreement to receive
   the artifact / book 15 min), not a close.

Output with persona, hooks + sources, and a "do NOT say" list. Ledger → Drafted.
